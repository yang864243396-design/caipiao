# 六合彩生肖玩法方案内容设计

## 目标

为“生肖特肖、生肖二肖、生肖三肖、生肖四肖、生肖五肖、生肖六肖”提供生肖专用的方案内容，使定码轮换、高级定码轮换、高级开某投某、冷热出号、随机出号和固定出号均不再使用 0–49 号码池。

## 适用玩法与内容格式

仅适用于 `lhc_std / g005` 的下列子玩法：

| 子玩法 ID | 玩法 | 必选生肖数 |
| --- | --- | --- |
| 302 | 特肖 | 1 |
| 304 | 二肖 | 2 |
| 305 | 三肖 | 3 |
| 306 | 四肖 | 4 |
| 307 | 五肖 | 5 |
| 308 | 六肖 | 6 |

方案内容使用十二生肖的逗号分隔格式，例如 `马,兔,龙`。每个生肖不可重复，且必须恰好满足该玩法的必选数量。

二全中、二中特和特串的生肖对碰仍是独立玩法：保留现有的两个生肖与 `肖A|肖B` 格式，不受本设计影响。

## 前端行为

新增一个按子玩法 ID 返回“生肖玩法规则”的共享识别器，向所有方案内容面板提供：是否是普通生肖玩法、十二生肖选项宇宙、必选数量和逗号格式化规则。

- 定码轮换、高级定码轮换和固定出号使用生肖点选面板；保存、预览和编辑回填均展示逗号分隔生肖。
- 高级开某投某的“开出”使用特码生肖；正投和反投使用生肖点选，并各自校验为该玩法的固定数量。
- 冷热出号的统计选项是十二生肖；名次选择数量固定为该玩法的数量，生成预览和保存内容为逗号分隔生肖。
- 随机出号固定随机抽取该玩法要求数量的互不重复生肖；配置回填与方案详情按同一格式显示。

总肖（303）不在本次范围内，维持现有行为。

## 后端行为

后端增加普通生肖玩法识别和规则解析，且优先于生肖对碰判断。

- 校验仅接受十二生肖、去重后必须恰好为规则数量，并以逗号分隔解析。
- 固定内容和高级开某投某沿用保存内容；触发开奖值为特码生肖。
- 随机出号从十二生肖中无重复抽取固定数量。
- 冷热出号按十二生肖统计特码在历史开奖中的出现频次，依规则数量取名次并生成逗号分隔内容。
- 注数计算和出站格式维持 `g005` 生肖玩法既有语义；普通生肖玩法不得套用生肖对碰的 `A|B` 号码展开逻辑。

## 测试与验收

前端测试覆盖六个子玩法的规则映射、格式化、错误数量拒绝、随机数量和各运行模式的生肖选项路由。

后端测试覆盖六个子玩法的合法与非法内容、随机生成、冷热生成、触发开奖生肖、注数为正及不进入生肖对碰格式化分支。

验收标准：任一适用玩法在六种方案模式中只展示十二生肖；内容数量严格符合玩法名；保存、详情、运行和第三方下单使用同一逗号分隔内容语义。

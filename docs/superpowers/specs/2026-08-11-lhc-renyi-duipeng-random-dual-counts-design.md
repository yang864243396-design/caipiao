# 二全中任意对碰随机出号双区数量设计

## 目标

二全中任意对碰在“随机出号”运行方式下，分别配置 A 区和 B 区的随机号码数量。每区至少一个号码，两个区合计不超过十个号码，且运行时生成的两区号码不得重复。

## 范围

仅在同时满足以下条件时启用双区数量配置：

- 玩法为六合二全中任意对碰（`betMode=renyi_dp`）；
- 运行方式为“随机出号”（`runTypeId=random_draw`）。

开某投某、冷热出号、固定选号及其他玩法继续沿用现有界面、配置和行为。

## 前端交互与配置

随机出号配置区显示两个独立步进器：`A区随机` 与 `B区随机`。

- A 区和 B 区各自取值范围为 1–9；
- 任意调整后始终满足 `A + B <= 10`；
- 初始值与回填值均归一化为合法的两个数量；
- 保存配置时，随机数量按 `[aCount, bCount]` 写入既有 `randomDraw.counts` 字段。

旧方案若只保存一个总数量 `n`（2–10），回填时按 `floor(n/2)` 与 `n-floor(n/2)` 拆分为 A/B，保留原总数量且确保两区都至少一个。非法或缺失的旧值回退为 `[1, 1]`。

## 运行时生成与校验

前后端均采用相同约束：

- 两个数量都必须至少为 1；
- 总数量不能超过 10；
- 随机池为 01–49；
- 对 01–49 执行一次随机洗牌，前 `aCount` 个作为 A 区，随后 `bCount` 个作为 B 区；
- 最终内容以 `A号码|B号码` 形式输出。

单次洗牌后顺序切分使两区天然不交叉。后端仍执行现有 A/B 格式、范围、跨区去重和总数上限校验，拒绝手工构造的非法配置或内容。

## 测试

- 前端：双区配置归一化、旧单值兼容、总数上限及生成内容的 A/B 数量和无重复。
- 后端：随机出号解析双区数量、生成内容满足 A/B 数量、拒绝 0、超过 10、跨区重复的结果。
- 回归：其他运行方式仍使用原有随机/选号逻辑，不显示或消费双区数量。

## 非目标

- 不改变开某投某的“全部随机”行为；
- 不调整现有下注注数计算；
- 不改变冷热出号的 A/B 名次配置。
